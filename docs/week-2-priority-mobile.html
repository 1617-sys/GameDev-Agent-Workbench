第二周任务拆分速读版

用途：手机上快速看清哪些任务只是推进进度，哪些任务真有技术含量。

一眼结论
先把基础 CRUD 做到能演示
-> 再挑 2 到 4 个高含量点做深
-> 让项目既完整，又有 AI 工程味

第一列：偏 CRUD

  • game_project CRUD
  • agent_run 列表、详情、按项目查询
  • agent_artifact 基础 CRUD
  • 项目基础信息编辑
  • 普通筛选和分页
  • README / Apifox / 数据库文档
  • 基础日志和异常处理
  • Python mock 接口扩充

特点：重复度高，结构固定，适合快速推进。

第二列：高含量任务

  • agent_run 绑定 project
  • 多步 Agent 工作流
  • agent_artifact 产物沉淀
  • 真实模型 API
  • 结构化 JSON 输出约束
  • 状态流转
  • 事务一致性
  • 超时、失败、重试
  • 项目上下文拼装
  • 复杂 SQL 聚合查询
  • 项目权限隔离
  • SSE、RAG、LangGraph、文件上传

特点：不是单表 CRUD，会碰到链路、状态、异常、权限，更接近真实 AI 工程项目。

你的项目现在有没有 AI 部分

Java 调 Python
-> AgentType 路由分发
-> Python 返回结构化结果
-> Java 保存 agent_run
-> 用户查询历史结果

现在已经有 AI 工程链路雏形，但还不算强模型能力型项目。

还缺：真实模型 API、多步编排、上下文记忆、产物复用。

最值得深做的 4 个点

  1. agent_run 和 project 绑定
  2. 真实模型 API 接入
  3. agent_artifact 产物沉淀
  4. 多步 Agent 工作流
