# FR-02：项目中心与游戏创作台

> 状态：`DONE`
>
> 前置任务：`FR-01`
>
> 推荐模型：`gpt-5.4`

## 目标

实现项目列表、创建、选择和游戏创意提交，让用户无需接触 UUID、Workflow Key 和幂等键。

## 范围

- 重新编写项目 API 和工作流提交 API。
- 侧栏项目列表、项目空状态和创建项目对话框。
- 游戏创作台、示例创意、可选上下文和提交状态。
- 固定提交 `GAME_GENERATE`，安全生成并复用 pending 幂等键。
- 成功后导航到服务端返回的运行 UUID。

## 非目标

- 不实现知识库、Prompt 指标和后台管理。
- 不增加后端字段和工作流类型。
- 不实现运行详情。

## 验收标准

- [ ] 用户可创建、刷新和选择项目。
- [ ] 用户不需要输入任何技术标识。
- [ ] 重复点击不会产生并发重复提交。
- [ ] 提交失败保留输入，成功后进入运行页。

## 验证命令

```powershell
cd frontend-vue
npm run test:unit
npm run build
```

## 完成定义

- 注册到提交的页面主链路可用，接口参数符合后端契约。
