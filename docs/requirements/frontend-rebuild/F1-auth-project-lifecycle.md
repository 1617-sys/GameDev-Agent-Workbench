# F1：认证与项目生命周期

> 状态：`TODO`
>
> 前置任务：无
>
> 推荐模型：`gpt-5.4`
>
> 任务类型：前端产品外壳 / API 契约接入

## 背景

当前前端只有不完整的登录入口，且用户登录后直接面对需要手填项目 UUID 的工作流表单。后端已经提供注册、登录、当前用户和项目 CRUD 接口，本任务先建立正常用户进入项目的基础链路。

## 目标

```text
注册或登录
-> 加载当前用户项目
-> 创建或选择项目
-> 进入该项目工作台
```

## 必读上下文

- `docs/frontend-rebuild-design.md`
- 后端 `AuthController`、`GameController` 及对应请求 DTO、返回 VO
- `frontend-vue/src/App.vue`
- `frontend-vue/src/api/authApi.js`
- `frontend-vue/src/api/httpClient.js`
- `frontend-vue/src/styles.css`

只在字段不明确时继续读取直接关联的 Service 或测试，不读取全部后端和历史 evidence。

## 范围

- 完成登录和注册模式切换及客户端基础校验。
- 复用当前会话认证机制，不新增持久化 Token。
- 新增项目 API 适配器，接入项目列表、创建、详情和更新契约。
- 实现项目列表、空状态、创建项目和项目选择。
- 调整 `App.vue`，建立认证页、项目页和工作台之间的有限页面状态。
- 为认证和项目 API 的关键映射补充轻量单元测试。
- 提供加载、请求失败、校验失败和退出登录状态。

## 非目标

- 不实现工作流提交、SSE、运行详情和产物展示。
- 不修改 Java 后端、数据库初始化数据或安全策略。
- 不实现找回密码、验证码、头像、个人中心和复杂权限管理。
- 不引入 Vue Router、Pinia、UI 组件库或表单库。
- 不把数据库账号当作业务账号，也不写死默认用户。

## 约束

- 注册和登录字段必须以后端 DTO 为准，不猜测字段。
- 401 必须清理当前认证状态并回到认证页。
- 不将 Token 写入 localStorage、URL 或日志。
- 项目 UUID 只能由服务端返回并由前端内部传递。
- 所有异步按钮在请求期间禁用，避免重复创建。
- 保留开始任务前已有的未提交修改，不覆盖无关 WIP。

## 验收标准

- [ ] 新用户可以注册，并使用业务账号登录。
- [ ] 已登录用户刷新应用时可以通过 `/api/auth/me` 恢复或确认会话。
- [ ] 可以加载项目列表，并正确展示空、失败和加载状态。
- [ ] 可以创建项目，创建成功后项目出现在列表中并可进入工作台。
- [ ] 用户界面不要求输入项目 UUID。
- [ ] 退出登录后敏感项目数据从界面状态中清除。
- [ ] 桌面和 375px 移动视口无明显遮挡或横向溢出。

## 验证命令

```powershell
cd frontend-vue
npm run test:unit
npm run build

cd ..
git diff --check
git diff -- frontend-vue
```

## 审查清单

- 是否误把 MySQL 用户名或密码作为业务登录凭据。
- 是否在浏览器持久化、URL、错误信息或日志中泄露 Token。
- 是否在创建成功后仍展示旧项目列表。
- 是否因 401 进入无限请求或重复登录循环。
- 是否为了页面切换引入了任务范围外的新框架。

## 完成定义

- 所有验收标准通过。
- 相关单元测试与 build 返回 0。
- diff 只包含认证、项目生命周期、必要样式和对应测试。
- 人工可以完成“注册/登录 -> 创建项目 -> 进入工作台”。
