## Purpose

提供项目隔离的知识文档管理和可解释的 RAG 来源视图，使用户能够看到真实的解析、索引与引用证据，同时避免前端直接检索向量库或泄露文档全文。

## ADDED Requirements

### Requirement: 项目知识库管理
授权用户 SHALL 能上传受支持文件、查看本项目文档列表、版本、状态、短摘要和安全错误信息；任何状态判断 MUST 以后端响应为准。

#### Scenario: 上传合法文档
- **WHEN** 用户上传满足大小与类型限制的文档
- **THEN** 页面显示后端返回的初始状态并持续刷新直到终态

#### Scenario: 上传非法文档
- **WHEN** 后端拒绝文件类型、大小、内容或权限
- **THEN** 页面显示可行动的安全错误且不将文档乐观标记为 READY

#### Scenario: 跨项目访问
- **WHEN** 用户尝试通过 URL 或文档 UUID 读取其他项目文档
- **THEN** 后端拒绝请求且前端不泄露文档是否存在

### Requirement: 实际 RAG 来源证据
运行详情 SHALL 展示该次 WorkflowRun 实际持久化的 RAG 引用，包括启用状态、文档与块标识、版本、排名、分数和安全摘要，并 MUST NOT 在页面打开时重新执行检索。

#### Scenario: 运行使用了 RAG
- **WHEN** 工作流具有持久化 RetrievalRecord
- **THEN** 页面按实际选择顺序展示来源及版本信息

#### Scenario: 没有检索证据
- **WHEN** RAG 关闭、没有候选、检索失败或运行使用 mock
- **THEN** 页面明确区分这些状态，不显示伪造引用

### Requirement: 知识内容安全
前端 MUST NOT 执行、信任或完整渲染文档中的脚本、HTML、Prompt 指令、路径或命令。

#### Scenario: 恶意文档内容
- **WHEN** 文档名称或安全摘要包含脚本和指令文本
- **THEN** 页面将其作为转义文本显示且不触发代码、导航或工具调用
