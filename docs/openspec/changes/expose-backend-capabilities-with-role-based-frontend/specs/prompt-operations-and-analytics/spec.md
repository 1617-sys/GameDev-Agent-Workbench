## Purpose

为授权管理员提供可审计的 Prompt 模板运维与 PromptVersion 指标视图，在不暴露密钥、完整敏感上下文和跨用户数据的前提下查看版本、质量、延迟和成本证据。

## ADDED Requirements

### Requirement: Prompt 模板管理
管理员 SHALL 能发现、查询、创建派生修改和更新允许编辑的 Prompt 模板；所有变更 MUST 显示目标模板、版本、影响范围并产生审计记录。

#### Scenario: 查询模板
- **WHEN** 管理员选择一个模板标识
- **THEN** 页面显示允许公开的元数据、系统模板和用户模板字段及版本状态

#### Scenario: 更新模板
- **WHEN** 管理员提交满足校验的更新并确认影响范围
- **THEN** 系统保存新状态、返回版本化结果并刷新页面

#### Scenario: 普通用户访问模板管理
- **WHEN** 非管理员打开模板管理路由或调用修改接口
- **THEN** 系统拒绝访问且不返回模板正文

### Requirement: PromptVersion 指标视图
管理员 SHALL 能按时间窗口、项目、Agent 类型和 mock 包含策略查询指标，并查看样本数、成功率、评测状态、延迟、token 与成本数据。

#### Scenario: 查询真实模型指标
- **WHEN** 管理员选择时间窗口且默认排除 mock
- **THEN** 页面展示后端聚合结果、单位、样本量和筛选条件，不在浏览器重新计算口径

#### Scenario: 零样本和数据缺失
- **WHEN** 查询没有样本、usage 缺失或评测不足
- **THEN** 页面显示明确的零样本、缺失或不足状态，不将其渲染为零成本或绿色成功

### Requirement: Prompt 安全与确认
Prompt 运维页面 MUST 隐藏密钥、Authorization、其他用户数据和不允许公开的模型原始输出，并对影响后续运行的写操作提供二次确认。

#### Scenario: 提交危险修改
- **WHEN** 管理员准备保存会影响活跃流程的模板修改
- **THEN** 页面展示差异、影响范围和确认步骤后才允许提交
